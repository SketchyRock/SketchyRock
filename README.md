# Hi, I'm Enzo

I'm a computer science student at James Madison University with a Russian minor. I do ML research, offensive and defensive security, and competitive programming. What they have in common is that I like problems that stay stuck for a while and then suddenly aren't.

## What I'm up to

**Research.** I'm a security researcher on HGN-Sense with Virginia CCI, a machine learning system that flags impaired drivers from their eye movements. My part is making it hard to abuse: encrypting the biometric data, checking model files for tampering, and hardening it against spoofing.

**Security.** I play both sides. On defense I administer Palo Alto firewalls and write incident response for MACCDC, where we qualified for regionals. On offense I play CTFs, and I built [runectl](https://github.com/IdaliaLabs), an open-source agent that drives Kali tools in Docker to solve challenges. It was part of how we won the Microsoft CTF at VMI Cyber Fusion and placed top 10 at Summit CTF. I write up what happened and what I got wrong in [writeups](https://github.com/SketchyRock/writeups).

**Problem solving.** I'm the president of JMU's Competitive Programming Club and I'm on the executive board of the Cyber Defense Club. At the 2026 ICPC Mid-Atlantic Regional our team solved 6 problems, first at the JMU site and top 11 in the region.

## Things I've built

- [**Echoes**](https://github.com/SketchyRock/echoes): anonymous voice notes pinned to real places on campus, which you can only hear by standing there. Go and React. 3rd place at the JMU Makeathon 2026.
- [**Gvoid**](https://github.com/SketchyRock/Gvoid): a deep work station with a Pomodoro timer, ambient sound, tasks, and a draggable widget layout. React and Vite.
- [**runectl**](https://github.com/IdaliaLabs): the CTF agent above, built under Idalia Labs.
- [**writeups**](https://github.com/SketchyRock/writeups): competition retrospectives and a Palo Alto firewall cheat sheet.
